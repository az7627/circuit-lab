# 电路实验室 v2.9.1

本次为修订版本，新增各平台的内核选择，修复 Android 系统主题与签名校验，并精简元件属性和实物外观。

## 两种内核版本

| 平台 | 内置浏览器内核 | 使用系统 WebView |
| --- | --- | --- |
| Windows x64 | 原版 EXE 安装程序 / 免安装程序，内置 Chromium | `system-webview` EXE 安装程序 / 免安装程序，使用已安装的 WebView2 |
| macOS ARM64 / Intel | 原版 DMG / ZIP，内置 Chromium | `system-webview` DMG / ZIP，使用系统 WKWebView |
| Linux x64 | 原版 AppImage / DEB，内置 Chromium | `system-webview` TAR.GZ / DEB，使用系统 WebKitGTK 4.1 |
| Android | `embedded` APK / AAB，内置 GeckoView，Android 8.0 及以上 | 原版 APK / AAB，Android 7.0 及以上 |

内置内核版体积更大，但运行时随应用提供。系统 WebView 版体积更小，需具备对应系统运行时：Windows 须已安装 Microsoft Edge WebView2 Runtime；Linux 轻量版面向 Ubuntu 24.04 或兼容环境，需要 `libwebkit2gtk-4.1-0` 和 `libgtk-3-0`。Linux 轻量版采用 DEB / 普通压缩包，避免 AppImage 再次携带 WebKit 内核。

所有版本均内置网页资源，可离线搭建电路。两种版本可共存，实验数据相互独立；切换版本请先导出 JSON，再在新版本导入。Android 用户直接安装 APK；AAB 用于应用商店分发。

## 修复与优化

- 修复 Android「跟随系统」深色模式，原生系统主题变化会传递到工作台，手动深色 / 浅色偏好仍优先生效。
- 修复深色模式下未通电灯泡、电铃电路符号及实物灯泡玻璃仍显示浅色的问题，保留通电发光反馈。
- 移除灯泡、电铃、电动机实物图上易与接线柱混淆的装饰螺丝。
- 删除元件属性中的说明副标题；窄屏或矮屏直接显示「电源E1」等标题，隐藏重复图标和名称行，保留悬浮卡片和画布尺寸。
- `.openai/` 已加入忽略规则并取消 Git 跟踪，本地配置继续保留。

## Android 签名与升级

- 后续发布固定沿用已确认的 **v2.9.0 发布证书**；构建前核对证书指纹及 GitHub Actions 中保存的公钥，缺少密钥或不匹配时停止发布，不生成替代私钥。
- 已重新签署并替换 v2.8.2 Release 的 Android APK / AAB，更新对应 SHA-256 校验值。核实发现 v2.8.2 与 v2.9.0 官方 release APK 原本就使用同一证书；旧 debug APK 则使用不同证书。
- v2.9.0 正式版可直接升级同一种 v2.9.1 正式版。若安装的是旧 debug APK，请先导出实验备份，再卸载旧调试包、安装正式版并导入。重新签署下载附件无法改变手机上已安装的旧调试包签名。
- 自本版本起 debug 包名独立，避免再次与正式版发生覆盖安装冲突。Android 系统版与内置版也分别使用独立包名。
