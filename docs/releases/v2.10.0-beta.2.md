# 电路实验室 v2.10.0-beta.2

- 元件库改用统一的指针拖动：鼠标、触控笔和手机手指均可直接拖到画布，无需长按。拖动时显示元件预览，松手按画布坐标放置；拖出画布、按 Esc 或手势中断会取消，点击添加和撤销重做仍可使用。
- 修复打包桌面版无法拖入元件的问题，停用原生 WebView 对拖放事件的接管。
- 修正顶栏“设置”图标的垂直位置，与其他操作图标居中对齐。
- 网页标题、桌面窗口、应用名和安装程序统一使用“电路实验室”，移除“轻量版”“系统 WebView 版”等名称后缀。
- Windows 恢复带应用图标的中文安装向导，支持选择目录和覆盖升级。默认安装到当前用户的 `CircuitLab` 目录，注册标识及实验数据目录保持固定，后续版本沿用已有安装位置并保留实验。
- 全平台继续使用系统 WebView，安装包不附带浏览器内核。v2.9.1 和 v2.10.0-beta.1 的 Windows 系统 WebView 包将同步重打包。

旧中文目录版本请先自行卸载，再安装新版；本次不迁移旧安装目录。新版之间可直接覆盖升级。

Windows 未做商业代码签名；macOS 使用 ad-hoc 签名，未经过 Apple 公证。Windows 需已安装 WebView2，Linux 需 WebKitGTK 4.1。Android 沿用既有正式签名证书。

附件包含 Windows x64、macOS ARM64/Intel、Linux x64 和 Android APK/AAB；`SHA256SUMS.txt` 用于校验下载文件。本版本为预发布版。
