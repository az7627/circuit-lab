# 电路实验室 v2.10.0-beta.3

- 修复连续调节电源电压、电阻或滑动变阻器时，电流方向动画反复从头播放、闪烁和抖动的问题。更新读数和导线路径时复用已有导线及动画节点，让电流动画持续播放。
- 修复电容充放电、电动机启动等动态模拟每秒更新多次时，同样反复重启电流动画的问题。电路图和实物图均适用。
- 新增动画连续性回归检查，覆盖逐帧调节电压和电流、动态模拟、电流显示开关、减少动态效果偏好，以及删除导线和撤销恢复。

继续使用系统 WebView、统一的“电路实验室”名称和中文安装向导。Windows 默认目录为英文 `CircuitLab`，可直接覆盖升级并保留实验。

本版本为预发布版。附件包含 Windows x64、macOS ARM64/Intel、Linux x64 和 Android APK/AAB；`SHA256SUMS.txt` 用于校验下载文件。
