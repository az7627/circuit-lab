# 电路实验室 v2.10.0

## 电路绘制与实物图

- 电路图新增连线时保留已有走线、节点和测量支路。分支处自动绘制实心节点，接线可吸附到附近的导线或接线柱。
- 电路图与实物图可独立排版并往返切换。自动布局会避开元件，并保留电表接线极性和量程。
- 实物图导线在高 DPI 和放大时更平滑。设置可开启曲线拟合，画线预览跟随指针，完成接线后再显示拟合曲线。电流方向动画在调节参数时连续播放。

## 模拟与参数

- 可调电池内阻，支持观察端电压跌落、内阻发热和短接电流。电动机支持反电动势和堵转模拟，电容支持充放电及慢放观察。新增发光二极管，亮度随正向电流变化。
- 扩大元件参数滑块范围，属性面板可直接输入范围以外的合法数值。设置可为新放置的元件保存参数预设。

## 桌面与移动端

- 界面缩放支持 25%–250%，每档 25 个百分点。触屏工具栏可滚动，元件可通过拖放或点击添加。
- 桌面端可隐藏系统标题栏，将窗口按钮合并到顶栏。应用标题、实验名和空白处可用于拖动窗口。Windows 支持触控拖动顶栏及边角缩放。
- Android 背景延伸至状态栏和导航栏，操作控件会避开系统栏和屏幕缺口。

Windows、macOS、Linux 和 Android 均使用系统 WebView，应用资源随安装包提供，可离线使用。Windows 需要 WebView2，Linux 需要 WebKitGTK 4.1。Android 沿用既有发布证书。

附件包含 Windows x64、macOS ARM64/Intel、Linux x64 和 Android APK/AAB。可用 `SHA256SUMS.txt` 核对下载文件。
