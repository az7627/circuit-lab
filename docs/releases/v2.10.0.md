# 电路实验室 v2.10.0

## 电路绘制与实物图

- 电路图新增连线时保留已有走线、节点和测量支路。分支处自动绘制实心节点，接线可吸附到附近的导线或接线柱。
- 电路图与实物图可独立排版并往返切换。自动布局会避开元件，并保留电表接线极性和量程。
- 实物图导线在高 DPI 和放大时更平滑。设置可开启曲线拟合，画线预览跟随指针，完成接线后再显示拟合曲线。电流方向动画在调节参数时连续播放。

## 模拟与参数

- 可调电池内阻，支持观察端电压跌落、内阻发热和短接电流。电动机支持反电动势和堵转模拟，电容支持充放电及慢放观察。新增发光二极管，亮度随正向电流变化。
- 扩大元件参数滑块范围，属性面板可直接输入范围以外的合法数值。设置可为新放置的元件保存参数预设。

## 桌面与移动端

- 界面缩放支持 25%–250%，每档 25 个百分点。触屏工具栏可滚动，元件可通过拖放或点击添加。
- 桌面端可隐藏系统标题栏，将窗口按钮合并到顶栏。应用标题、实验名和空白处可用于拖动窗口。Windows 支持触控拖动顶栏及边角缩放。
- Android 背景延伸至状态栏和导航栏，操作控件会避开系统栏和屏幕缺口。

Windows、macOS、Linux 和 Android 均使用系统 WebView，应用资源随安装包提供，可离线使用。Windows 需要 WebView2，Linux 需要 WebKitGTK 4.1。Android 沿用既有发布证书。

附件包含 Windows x64、macOS ARM64/Intel、Linux x64 和 Android APK/AAB。可用 `SHA256SUMS.txt` 核对下载文件。

### 电路实验室 v2.10.0-beta.1

电路实验室 2.10.0 首个预发布版本。本次大版本包含电路图智能编辑布线、电路图与实物图高级互转、元件物理模型升级，并全面转向系统 WebView 轻量版构建与纯净包名。

#### 电路图编辑与智能布线

- **增量接线保护**：新增连线时保留现有手绘线路、手动节点和测量支路，规划正交直角避障走线，避开器材本体及文字。
- **复杂测量与短路跨接**：修复接入电压表、直接短接用电器、经手动节点跨接时线路被整体重排压扁的问题。
- **智能节点打点**：分支与 T 型接线处自动绘制实心导线节点，普通转角不打点。
- **端子智能吸附**：连线结束时光标靠近接线柱或现有导线段自动高亮并吸附。

#### 电路图与实物图互转

- **拓扑识别与独立布局**：先通过拓扑分析识别串并联关系、分流汇流点及支路顺序，再根据器材外形及接线柱朝向独立排布实物，不拘泥于电路图的二维几何位置。
- **无交叉严格校验**：自动实物转换结果必须通过严格的无交叉碰撞检查；若无法形成无交叉布局则保留原电路并友好提示，坚决不呈现凌乱交叉的错误排布。
- **真实接线柱汇接与自然弧线**：导线采用平滑连续的自然弧线汇接至器材实际接线柱，并联支路走线更贴近真实物理实验。
- **测量与极性保留**：完整保留电流表、电压表的正负接线柱极性、接入量程及测量范围；大幅优化大规模网格图的分析转换速度。

#### 元件模型与物理特性升级

- **电池内阻可调**：支持设定电源电动势与内阻（默认为 0 Ω 兼容旧实验），模拟端电压跌落与内阻发热计算。
- **电动机机电模型**：采用 $U = E_反 + Ir$ 模型，引入反电动势、转动惯量、摩擦阻尼与转子堵转模拟，属性面板支持长按转子观察堵转电流激增。
- **电容器暂态特性**：采用后向欧拉算法模拟电容充放电、储能及断电放电动态，支持 10 倍与 100 倍慢放观察暂态变化。
- **新增 LED 元件**：加入发光二极管，正向导通且带有内阻压降，反向截止，亮度随正向电流变化，超量程提示串联限流电阻。

#### 元件外观与反馈细节

- **滑动变阻器端子规范**：标准改为下方两个固定端（A、B）、上方一个滑片端（P），阻值调节与分压接法更符合中学物理教材。
- **电铃声振动态反馈**：电铃 Web Audio 发声同步改变敲击频率与锤头振幅，供电越强响度与敲击越快。
- **外观精简**：移除小灯泡底座上容易被误当成接线柱的装饰螺钉，避免误接线。

#### 存储、兼容与错误处理

- **缓存与配额修复**：修复删除元件后旧视图缓存引用残留导致偶发“存储空间不足”误报的问题。
- **精细化错误提示**：细分并提示数据校验错误、本地存储配额不足以及存储权限受阻。
- **全流程几何保真**：完整保留手绘布局、撤销/重做、保存/重载以及往返互转的导线路径。

#### 构建与架构升级

- **默认系统 WebView**：全平台全面使用操作系统自带的系统 WebView（Windows WebView2 / macOS WKWebView / Linux WebKitGTK 4.1 / Android 系统 WebView），不再构建体积庞大的内置内核版本。
- **纯净包名**：移除产物名中的 `-system-webview` 和 `-embedded` 后缀，安装包体积大幅缩小，下载更轻快。
- **自动化预发布流程**：GitHub Actions 支持检测 `-alpha`、`-beta`、`-rc` 标签并自动标记为 GitHub Pre-release，不覆盖稳定版的 Latest 标记。

- **微小读数归零**：电流绝对值小于 `1e-6 A`、电压绝对值小于 `1e-3 V` 时统一视为零，数字读数、电表指针、导线动画和通电反馈保持一致。电容充放电等内部计算仍保留精度。

新增归零边界、触屏横纵向滚动、长按与取消、触屏电脑鼠标直拖、深色拖动、界面缩放及重启恢复回归检查。延续 beta.3 的电流动画连续性修复。

### 电路实验室 v2.10.0-beta.5

- **LED 调光**：新发光二极管的默认正向压降为 2.4 V，滑块可调 1.2–4.5 V。将 LED 与 0–20 Ω 滑动变阻器串联，在 3 V、4.5 V 或 6 V 下均可观察到亮度随电流变化。超过 20 mA 时，元件属性会提示过流。
- **界面缩放**：设置改用滑块，范围为 25%–250%，每档相差 25 个百分点。
- **Android**：应用背景延伸到透明状态栏和导航栏后方，操作控件避开系统栏和屏幕缺口。全屏和系统返回键仍可恢复系统栏。
- **桌面版**：可在设置中开启「隐藏标题栏」。拖动顶栏可移动窗口，最小化、最大化和关闭合并到顶栏。macOS 的红绿灯位于左侧，Linux 按桌面设置排列按钮。启用该功能后，顶栏只可在全屏中收起。
- **元件参数**：扩大参数滑块的范围。也可在属性面板直接输入合法数值，支持滑块范围以外的数值与小数精度。设置中的「元件参数预设值」对新添加的元件生效，并随实验备份保存。
- **短接模拟**：短接后直接计算电流、旁路元件读数和内阻发热。未设内阻的理想电源在被短接时按每节 0.5 Ω 等效内阻计算。

本版本为预发布版。附件包含 Windows x64、macOS ARM64/Intel、Linux x64 和 Android APK/AAB，校验值见 `SHA256SUMS.txt`。Windows 需要系统 WebView2，Linux 需要 WebKitGTK 4.1。Android 沿用固定发布证书。
