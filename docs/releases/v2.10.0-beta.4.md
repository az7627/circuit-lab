# 电路实验室 v2.10.0-beta.4

- **微小读数归零**：电流绝对值小于 `1e-6 A`、电压绝对值小于 `1e-3 V` 时统一视为零，数字读数、电表指针、导线动画和通电反馈保持一致。电容充放电等内部计算仍保留精度。
- **触屏滚动与拖动分离**：根据实际触摸事件和工具栏是否溢出判断操作方式。触屏且工具与元件栏需要滚动时，滑动元件用于滚动，按住约 0.4 秒、元件高亮后才能拖出；鼠标、触控笔，以及不需要滚动的触屏仍可直接拖动。支持横向、纵向滚动和滚动惯性，点击添加、取消拖动与撤销重做继续可用。
- **修复深色拖动白底**：移除元件卡片按住状态写死的浅色背景，拖动源卡片、就绪高亮和预览均适配深浅色。
- **UI 缩放比例**：设置中新增 75%～200% 的界面缩放，默认 100%，重启后保留。栏位、菜单、对话框和拖动预览随界面比例适配，画布落点仍准确。

新增归零边界、触屏横纵向滚动、长按与取消、触屏电脑鼠标直拖、深色拖动、界面缩放及重启恢复回归检查。延续 beta.3 的电流动画连续性修复。

本版本为预发布版，全平台使用系统 WebView。Windows 默认安装目录为英文 `CircuitLab`，支持覆盖升级并保留实验。附件包含 Windows x64、macOS ARM64/Intel、Linux x64 和 Android APK/AAB，校验值见 `SHA256SUMS.txt`。
