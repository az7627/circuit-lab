# 电路实验室

面向中学生的中文直流电路虚拟实验室。使用原生 HTML、CSS、JavaScript 和 SVG，无需安装依赖。

运行 `npm run dev`，打开 http://127.0.0.1:4173 。运行 `npm test` 检查电路求解器，`npm run check` 检查交互代码语法。

## 功能

- 13 种元件：电源、灯泡、电阻、开关、电流表、电压表、滑动变阻器、电动机、电铃、电热丝、电容、线圈、保险丝。
- 任意位置放置接线节点、导线内插入节点、从节点引出多条支路、拖动节点与元件调整走线；删除、旋转与撤销。
- 串联、并联、欧姆定律预设及自由搭建。
- 按真实连接拓扑求解电压、电流和电功率；短路与开路检测。
- 实时仪表、灯泡亮度、电流方向；实验数据记录、散点图和 CSV 导出。
- 浏览器本地保存、实验步骤与键盘操作、响应式布局。

点击工具栏的接线节点按钮或按 `J`，点击空白处放置节点、点击导线插入节点；选择模式双击导线也可插入。按 `W` 连线，从端子或节点开始，依次点击空白处创建拐点，最后点击目标端子结束。实心节点处的所有支路互相接通；普通导线交叉不接通。节点支持拖动、方向键移动、删除和撤销。

采用理想直流电源、零电阻导线和电流表、无限电阻电压表。灯泡、电动机、电铃、电热丝以电阻近似；电动机采用圈内 M 的图形，不标正负极，电铃仅显示通电指示，无声音。滑动变阻器下端连接电阻丝固定端，上端连接滑片，调节有效电阻时滑片箭头会移动，端子位置保持固定。灯泡的填充颜色与有限范围的光晕随电功率变化，不模拟温度。电容稳态直流时断路，理想线圈稳态直流时短路，不模拟充放电或其他暂态。保险丝冷态电阻 0.2 Ω，电流超过可调额定值时自动熔断，可更换。不模拟电源内阻和电表量程。工作台限制为一个电源、40 个元件、100 个节点及 200 根导线。旧蜂鸣器和变阻器的电路存档会兼容升级，保留电气连接及实验记录。

画布尺寸独立于右侧属性内容，选择元件会保留当前镜头和手动缩放比例。使用 `F` 或全屏按钮全屏显示画布，`Esc` 或退出按钮恢复；支持浏览器原生全屏，嵌入浏览器不允许原生全屏时展开到页面全屏。`0` 或适应画布按钮会重新计算居中位置及缩放比例，显示全部元件、节点及走线。

电铃图形参考科学出版社《学会电工识图的10堂课》1.12 节的向上半圆和两条引线示意：[出版社原文](https://www.ecsponline.com/yz/BFC0B9B8DF9984E41B9ED007856D65E2F000.pdf)。

部署文件位于 `dist/`，Sites 配置位于 `.openai/hosting.json`。
